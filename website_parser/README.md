# 🕷️ Веб-парсер для извлечения контента в CSV

Мощный и гибкий веб-парсер на Python для извлечения контента с веб-сайтов и сохранения данных в CSV формат.

## 🚀 Возможности

- ✅ Парсинг одной или нескольких веб-страниц
- ✅ Гибкая настройка CSS селекторов для извлечения данных
- ✅ Автоматическое сохранение в CSV формат с поддержкой UTF-8
- ✅ Обработка ошибок и повторные попытки
- ✅ Логирование всех операций
- ✅ Настраиваемые задержки между запросами
- ✅ Поддержка пользовательских заголовков HTTP
- ✅ Извлечение ссылок и базовой информации о страницах
- ✅ Цветной вывод в консоли
- ✅ Готовые примеры для разных типов сайтов

## 🛠️ Быстрый старт

### Базовое использование

```python
from website_parser import WebsiteParser

# Создаем экземпляр парсера
parser = WebsiteParser()

# Определяем селекторы для извлечения данных
selectors = {
    'title': 'h1',
    'content': '.content, p',
    'author': '.author',
    'date': '.date, time'
}

# Парсим одну страницу
url = "https://example.com/article"
data = parser.parse_single_page(url, selectors)

# Сохраняем в CSV
if data:
    parser.save_to_csv([data], "article_data.csv")
```

### Парсинг нескольких страниц

```python
# Список URL для парсинга
urls = [
    "https://example.com/article1",
    "https://example.com/article2",
    "https://example.com/article3"
]

# Парсим все страницы
all_data = parser.parse_multiple_pages(urls, selectors)

# Сохраняем все данные в один CSV файл
parser.save_to_csv(all_data, "articles_data.csv")
```

## ⚙️ Конфигурация

Настройки хранятся в файле `config.json`:

```json
{
    "headers": {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
    },
    "timeout": 15,
    "delay": 2,
    "max_retries": 3,
    "output_file": "parsed_data.csv",
    "log_level": "INFO"
}
```

### Параметры конфигурации:

- `headers` - HTTP заголовки для запросов
- `timeout` - таймаут запроса в секундах
- `delay` - задержка между запросами в секундах
- `max_retries` - количество повторных попыток при ошибке
- `output_file` - имя файла по умолчанию для сохранения
- `log_level` - уровень логирования (DEBUG, INFO, WARNING, ERROR)

## 🎯 CSS Селекторы

Парсер использует CSS селекторы для извлечения данных. Примеры:

### Основные селекторы:
- `h1` - заголовок первого уровня
- `.class-name` - элемент с определенным классом
- `#element-id` - элемент с определенным ID
- `tag[attribute]` - элемент с атрибутом
- `.parent .child` - вложенные элементы

### Готовые наборы селекторов:

#### Для новостных сайтов:
```python
news_selectors = {
    'title': 'h1, .title, .headline',
    'content': '.content, .article-body, p',
    'author': '.author, .byline',
    'date': '.date, .published, time',
    'tags': '.tags a, .categories a'
}
```

#### Для интернет-магазинов:
```python
product_selectors = {
    'name': 'h1, .product-title',
    'price': '.price, .cost',
    'description': '.description, .product-desc',
    'rating': '.rating, .stars',
    'availability': '.stock, .availability'
}
```

#### Для блогов:
```python
blog_selectors = {
    'title': 'h1, .post-title',
    'content': '.post-content, .entry-content',
    'author': '.author, .post-author',
    'date': '.post-date, .entry-date',
    'comments_count': '.comments-count'
}
```

## 📊 Формат выходных данных

Данные сохраняются в CSV файл с кодировкой UTF-8. Структура:

| url | title | content | author | date | ... |
|-----|-------|---------|--------|------|-----|
| https://example.com | Заголовок | Текст статьи | Автор | 2024-01-01 | ... |

## 🔧 API Документация

### Класс WebsiteParser

#### Методы:

**`__init__(config_file="config.json")`**
- Инициализация парсера с конфигурационным файлом

**`fetch_page(url: str) -> BeautifulSoup`**
- Получение и парсинг HTML страницы
- Возвращает объект BeautifulSoup или None при ошибке

**`extract_data(soup: BeautifulSoup, selectors: Dict[str, str]) -> Dict[str, Any]`**
- Извлечение данных из HTML по CSS селекторам
- Возвращает словарь с извлеченными данными

**`parse_single_page(url: str, selectors: Dict[str, str]) -> Dict[str, Any]`**
- Парсинг одной страницы
- Возвращает извлеченные данные или None

**`parse_multiple_pages(urls: List[str], selectors: Dict[str, str]) -> List[Dict[str, Any]]`**
- Парсинг нескольких страниц
- Возвращает список извлеченных данных

**`save_to_csv(data: List[Dict[str, Any]], filename: str) -> str`**
- Сохранение данных в CSV файл
- Возвращает путь к сохраненному файлу

**`extract_links(soup: BeautifulSoup, base_url: str, link_selector: str) -> List[str]`**
- Извлечение ссылок со страницы
- Возвращает список абсолютных URL

**`get_page_info(url: str) -> Dict[str, Any]`**
- Получение базовой информации о странице
- Возвращает метаданные страницы

## 🚨 Обработка ошибок

Парсер обрабатывает различные типы ошибок:

- **Сетевые ошибки** - автоматические повторные попытки
- **Таймауты** - настраиваемое время ожидания
- **HTTP ошибки** - логирование и пропуск проблемных страниц
- **Ошибки парсинга** - продолжение работы с другими элементами

## 💡 Советы по использованию

### 1. Выбор правильных селекторов
- Используйте инструменты разработчика браузера (F12)
- Тестируйте селекторы в консоли: `document.querySelectorAll('selector')`
- Предпочитайте стабильные селекторы (ID, классы)

### 2. Этичный парсинг
- Устанавливайте разумные задержки между запросами
- Проверяйте robots.txt сайта
- Не перегружайте серверы частыми запросами
- Соблюдайте условия использования сайтов

### 3. Оптимизация производительности
- Используйте сессии для повторных запросов к одному домену
- Настройте подходящие таймауты
- Обрабатывайте данные порциями для больших объемов

### 4. Отладка
- Включите DEBUG логирование для подробной информации
- Используйте `get_page_info()` для анализа структуры страниц
- Тестируйте на небольших выборках перед массовым парсингом
